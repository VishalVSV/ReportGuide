# What is this document?

This document was written by two Master's students who were frustrated by the complete lack of education when it comes to scientific writing. We are not taught LaTeX, we are not taught how to write, we are not taught grammar and standard practice. Scientists are expected to learn these things by experience, however, this is their entire job and it is not particularly hard to teach. So we wrote a document with our experience and advice. This is not professional advice. Do not blame us if your professor gives contradictory advice (please add it to the document if so). 

# I don't see a PDF...

You should build it yourself. I believe every scientist should have a functioning version of LaTeX on their machine. This document should be relatively easy to build (there are some strange packages but you can open an issue if you face issues getting it to build). Just clone it to your favorite directory

```zsh
git clone https://github.com/VishalVSV/ReportGuide.git
```

and build it 

```
cd ReportGuide
make
```

That's it.
